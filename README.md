# まきぐも (Makigumo Bot)

サーバーに常駐してユーザーを監視・癒やし・お仕置きするDiscord Botです。

## 概要・主な機能
- **チャット自動反応**: 特定のキーワード（おはよ、おやすみ、かわいい 等）に反応して返信します。
- **シチュエーション・お遊び**: `/ガチャ`、`/看病`、`/罵倒` などのロールプレイコマンドを提供します。
- **ギャンブル・カジノシステム**: 変態ポインツを使った `/gamble`、`/slot` などのミニゲームが遊べます。
- **ショップ・アイテム機能**: 貯めたポインツでアイテムを購入・使用できます。

## 必要な環境
- Python 3.8 以上推奨
- 依存ライブラリ: `discord.py`, `python-dotenv`

## セットアップ方法
1. リポジトリをクローンまたはダウンロードします。
2. 必要なパッケージをインストールします。
   ```bash
   pip install discord.py python-dotenv
   ```
3. `.env.example` をコピーして `.env` ファイルを作成し、DiscordのBotトークンを設定します。
   ```bash
   cp .env.example .env
   # .env ファイルを編集し、DISCORD_TOKEN を記述してください
   ```
   **注意**: `.env` にはDiscordのトークンなど、他人に渡してはいけない情報が入ります。公開・共有しないでください。

## 起動方法
```bash
python main.py
```

## 構成と設定
- `main.py`: Botのメインプロセス
- `cogs/`: 各種機能（イベント、エコノミー、ロールプレイ）のモジュール
- `lines/`: セリフテキストデータ
- 各種 `.json` ファイル: 実行時に自動生成されるデータファイル（設定、ポインツなど）
